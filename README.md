# AG2 Platform

Static, responsive Thai-language dashboard prototype based on the supplied AG2 specification.

## Run
Open `index.html` directly or serve the repository with any static server. No secrets or backend credentials are required.

## Included
- 45 linked dashboard pages
- Responsive sidebar and theme toggle
- Local demo data and browser-local theme preference
- Safe static frontend scaffold ready for API integration

This repository does not claim that the documented production API, database, authentication, or infrastructure are implemented. Add those services separately before deployment.
