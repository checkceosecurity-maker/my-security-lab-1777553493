# Auth0 Setup Guide for AG2 Platform\n\n## Step 1: Create Single Page Application (SPA) in Auth0\n\n1. Go to Auth0 Dashboard → Applications → Applications\n2. Click **\"Create Application\"**\n3. Fill in:\n   - **Name:** `My App` (หรือชื่ออื่นๆ)\n   - **Application Type:** Select **\"Single Page Web Application\"**\n4. Click **\"Create\"**\n\n## Step 2: Configure Application Settings\n\nAfter creating the app, go to **Settings** tab and set:\n\n### Allowed Callback URLs\n```\nhttps://my-security-lab-1777553493.vercel.app/login.html\n```\n\n### Allowed Logout URLs\n```\nhttps://my-security-lab-1777553493.vercel.app/login.html\n```\n\n### Allowed Web Origins\n```\nhttps://my-security-lab-1777553493.vercel.app\n```\n\n### Save these values:\n- **Domain** (ค่า AUTH0_DOMAIN) - เช่น `your-tenant.us.auth0.com`\n- **Client ID** (ค่า AUTH0_CLIENT_ID) - ตัวอักษรและตัวเลขยาว\n\n## Step 3: Create API in Auth0\n\n1. Go to Auth0 Dashboard → Applications → APIs\n2. Click **\"Create API\"**\n3. Fill in:\n   - **Name:** `AG2 Platform API`\n   - **Identifier:** `https://ag2-platform-api`\n   - **Signing Algorithm:** Leave as `RS256`\n4. Click **\"Create\"**\n\n## Step 4: Set Environment Variables in Vercel\n\n1. Go to your Vercel project settings → Environment Variables\n2. Add these variables:\n\n```\nAUTH0_DOMAIN = your-tenant.us.auth0.com\nAUTH0_CLIENT_ID = (copy from Auth0 application Settings)\nAUTH0_AUDIENCE = https://ag2-platform-api\nFRONTEND_ORIGIN = https://my-security-lab-1777553493.vercel.app\nDATABASE_URL = postgresql://...(your postgres connection string)\nPORT = 8000\n```\n\n## Step 5: Test Locally\n\n1. Update `.env` file locally:\n```bash\nAUTH0_DOMAIN=your-tenant.us.auth0.com\nAUTH0_CLIENT_ID=your-client-id\nAUTH0_AUDIENCE=https://ag2-platform-api\nDATABASE_URL=sqlite:///./ag2_platform.db\nFRONTEND_ORIGIN=http://localhost:8000\n```\n\n2. Update `login.html` temporarily:\n```javascript\nconst AUTH0_DOMAIN = 'your-tenant.us.auth0.com';\nconst AUTH0_CLIENT_ID = 'your-client-id';\n```\n\n3. Run:\n```bash\npip install -r requirements.txt\nuvicorn api.index:app --reload\n```\n\n4. Open `http://localhost:8000` and click login\n\n## Step 6: Deploy to Vercel\n\n1. Push to GitHub\n2. Vercel automatically deploys from `master`\n3. Environment variables are picked up from Vercel settings\n\n## Troubleshooting\n\n### \"Invalid Auth0 token\" error\n- Check that `AUTH0_DOMAIN` and `AUTH0_AUDIENCE` are correct\n- Verify the API identifier in Auth0 matches `AUTH0_AUDIENCE`\n- Check that callback URL is registered in Auth0 app settings\n\n### Callback URL mismatch\n- Make sure Vercel URL matches exactly:\n  ```\n  https://my-security-lab-1777553493.vercel.app/login.html\n  ```\n\n### Token not recognized\n- Clear browser cache and localStorage\n- Re-login\n- Check Auth0 API settings have RS256 enabled\n\n## Security Notes\n\n⚠️ **Never commit:**\n- `.env` files with secrets\n- AUTH0_CLIENT_SECRET (if using confidential client)\n- Database connection strings\n\n✅ **Always use:**\n- Vercel Environment Variables for production\n- HTTPS only in production\n- Strong, unique CLIENT_ID per environment\n"
